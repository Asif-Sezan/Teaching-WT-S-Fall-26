#### Topics Covered:

##### JavaScript:

1. Adding JavaScript to a page
    - Internal JS (`<script>` tag in the HTML file)
    - External JS (`script.js` linked with `<script src="...">`)
2. Events
    - `document.getElementById()` to select an element
    - `addEventListener()` needs two things:
        1. which event (e.g. `click`)
        2. what to do (a. define a function, b. directly say what to do)
3. Variables and Data Types
    - `let` and block scope
    - Number (integer and decimal), string, boolean
    - `undefined` (set automatically at declaration, both type and value) vs `null` (must be set manually)
    - Array, object, function
    - Checking types with `typeof`
4. Strings
    - Single vs double quotes
    - Escaping quotes with `\`
5. Printing to the console with `console.log()`

#### Files:

- `index.html` - button with a `click` event listener calling a function (internal JS)
- `script.js` - variables, data types, `typeof`, objects, arrow functions, string quotes (external JS)
