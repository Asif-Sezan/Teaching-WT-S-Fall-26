#### Topics Covered

##### JavaScript DOM Manipulation

- Selecting elements with `querySelectorAll` and `querySelector`
- Creating elements with `document.createElement`
- Adding elements to the page with `appendChild`
- Updating element content with `innerText` and `innerHTML`
- Changing element styles with `element.style`
- Iterating over selected elements
- Responding to button clicks with inline `onclick` event handlers

##### JavaScript Data and Iteration

- Arrays of objects and accessing object properties
- Accessing array elements
- Functions for creating and adding table rows
- Iterating over an array with `forEach`
- Iterating over arrays with `for...of`
- Object properties with dot and bracket notation
- Object methods and the `this` keyword
- Dynamically creating an HTML table from array data
    - Creating table elements, rows, and cells
    - Displaying array data in a table
